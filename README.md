# Cline Pass 上游控制台 · 增强分支

本仓库是 [munmunjaklin458-afk/cline-pass-switcher](https://github.com/munmunjaklin458-afk/cline-pass-switcher)
的增量分支（基线：上游 `02538a3`，2026-09-11）。

功能全貌、安装部署方式、环境变量与配置字段说明都在
[上游 README](https://github.com/munmunjaklin458-afk/cline-pass-switcher#readme)，
本文件只记录本分支相对上游的更新日志。升级不需要改配置、不新增依赖。

## 更新日志

### 2026-09-21

**账号额度**

- 用户现在可以在「账号管理」里直接看到每个账号还剩多少额度：5 小时 / 本周 / 本月三条滚动窗口各自的进度条与已用百分比，接近上限时自动变色提醒（过半转橙、八成转红），并给出上限金额、重置时间与套餐状态。
- 每个账号那一行都有独立的「↻」按钮：点一次只刷新这一个账号，等待时间更短，也不会再把其它账号的额度挤成「读取失败」。
- 遇到偶发网络抖动时，页面会继续显示上一次读到的额度，并注明「读取失败，显示上次结果」；只有确实读不到数据时才提示失败、说明原因，不再让整行直接变成红字。
- 本地改过但还没保存的账号行不会被显示成别人的额度：对不上就显示「—」，不会拿错数据充数。
- 额度是只读的账单查询：不消耗订阅额度、不计费。

**请求历史**

- 请求历史右上角新增「↻ 刷新」按钮：不用刷新整个页面就能看到最新记录，刷新过程中按钮提示「刷新中…」。

**稳定性**

- 上游网络偶发抖动时，代理会自动重试，请求更容易正常完成，而不是直接把失败抛给客户端。
- 失败时给出的原因更具体（连接超时、连接被重置、等待超时、客户端主动断开等），排查问题更快。
- 单条流式请求遇到上游断链时，只会结束这一条连接，不再让整个代理掉线、连累所有正在使用的用户。
- 代理增加异常兜底：单条请求出问题不再导致整个服务退出。

## 升级方式

- 已有部署替换应用文件即可：后端改动重启代理生效，页面改动刷新浏览器生效，不需要重新部署。
- 配置无需迁移：账号池、上游钉住配置、代理密钥原样继续用；环境变量与依赖也没有变化。

## 安装本分支

```bash
git clone https://github.com/somehow-paul/cline-pass-switcher-update.git
cd cline-pass-switcher-update
node server.js        # 仅需 Node ≥ 18，无需 npm install
```
